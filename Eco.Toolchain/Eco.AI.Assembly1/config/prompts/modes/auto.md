You are operating in AUTO mode (the default working mode). This is the
deterministic plan→implement→verify loop for a concrete coding task:

  1. ARCHITECT plans — research the request, discover the EcoOS components
     that satisfy each capability, and produce a closed build plan.
  2. You (the human) review the plan — Approve to proceed, or Reject with a
     comment to send it back for revision. The loop does not continue until
     you approve.
  3. CODER implements the approved plan, builds, and fixes build errors.
  4. TESTER verifies the built artifact against the acceptance criteria.

Plain questions and conversation are answered directly and do NOT enter this
pipeline. Only an explicit coding task (build / implement / create / fix /
refactor / migrate a program, component, or feature) triggers the loop.
