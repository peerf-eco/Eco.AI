=== SKILL: ECO-WIZARD SCAFFOLDING ===

You generate structure ONLY through the `eco_wizard` tool — never hand-write
project boilerplate (directory trees, IdEco*/IEco* skeletons, factories,
Makefiles, .code-workspace) in your response.

# WHEN TO CALL
- New project / component / application / library / kernel scaffold → call
  BEFORE writing any file.
- Existing scaffold present → adapt it; do not regenerate over existing files.
- Missing binary → report the actionable error once and continue with the
  plan; do NOT silently substitute hand-written templates unless the task
  explicitly demands it.

# ARGUMENT CHEAT-SHEET (tool args map 1:1 to CLI flags)
- name:        Eco-prefixed CamelCase (`Eco.List1`). Wizard adds `Eco.` if absent.
- project_type COM    → component (factory + vtbls) — DEFAULT choice
               LIB    → static/dynamic library, no entry point
               APP    → executable application (generates EcoMain glue)
               ECOOS  → microkernel | LINUX → kernel | BOOT → bootloader
- language:    C or CPP ONLY. The wizard REJECTS Python/Java — for those,
               follow the task spec directly instead of calling the tool.
- options:     comma-free list of codes:
               pn  namespace postfix on identifiers
               cp  connection points (events/sinks) — only if the plan needs them
               ai/ao/co  aggregation inner/outer, containment outer (COM-style)
               ut  unit-test project (include for components)
               ts  thread-safe skeletons (only when concurrency is planned)
               Do not add unused options: each widens generated surface.
- use_env_framework: keep true — resolves dependencies from $ECO_FRAMEWORK.

# AFTER GENERATION
1. Verify the returned out_dir tree (list_dir) matches the plan's layout
   (SharedFiles/HeaderFiles/SourceFiles/AssemblyFiles/...).
2. Fill generated TODOs; preserve exact factory symbol
   `GetIEcoComponentFactoryPtr_<32-hex CID>` and UGUID blocks.
3. Report one concise structural summary; details stay in traces.
