# V7: оптимизация токенов и LLM-вызовов

Набор правок V7-пайплайна (`/ws/v7/chat`), сокращающих расход токенов, число
LLM-вызовов и действий кодера. Подтверждены 6 e2e-прогонами на эталонной задаче
(подробный разбор с цифрами — `diploma/analysis/agent-changes-report.md` и
`token-optimization-report.md`).

## Что включено по умолчанию (kill-switch через env)

Эти правки — проверенные победители, активны без настройки. Отключаются только
явным `=0`.

| Механизм | Что делает | Выключить |
|---|---|---|
| **Scaffold** | Кладёт в `project_dir/src` готовый `EcoMain.c` (скелет точки входа с QI-цепочкой) + `Makefile` с верными флагами и порядком линковки. Кодер адаптирует, а не выводит с нуля. Перевернул исход fail→SUCCESS, сборка с 1-й попытки. | `V7_SCAFFOLD=0` |
| **Pre-pull фреймворка** | Копирует 5 всегда-обязательных компонентов (Core1, InterfaceBus1, MemoryManager1, FileSystemManagement1, System1) из `marketplace_cache` в `project_dir` до кодера. Убирает цикл ручного копирования заголовков (был до 21 вызова `write_file`). | `V7_PREPULL_FRAMEWORK=0` |
| **Дедуп инструментов** | Повторный идентичный read-only вызов (read/glob/grep/...) возвращает короткий указатель вместо повторного полного результата. Memo сбрасывается мутирующими вызовами (write_file/run_build). | `V7_TOOL_DEDUP=0` |
| **Ретрай транзиентных ошибок** | 3 повтора LLM-вызова с бэкоффом 5/10/15 с на 5xx/520/529/timeout. 4xx не ретраятся. Обязателен при пине провайдера (нет router-failover). | (всегда вкл) |
| **Захват usage + cost** | Читает `usage` из любого SSE-чанка (OpenRouter шлёт в финальном с `choices`) + `usage:{include:true}`. Делает расход измеримым в трейсах. | (всегда вкл) |
| **Слим tool-результатов** | `run_build` при rc=0 → одна строка (лог в details); `read` дефолт-страница 32 КБ; `list_dir` кап 200 записей. | (всегда вкл) |

## Что нужно включить вручную

| Механизм | Зачем | Как |
|---|---|---|
| **Пин провайдера** | Включает implicit prompt-cache GLM: кэш 0%→95%, цена прогона −75%. Без пина OpenRouter раздаёт запросы по разным провайдерам и кэш не работает. | `OPENROUTER_PROVIDER_PIN=z-ai` в `.env`. **Имя обязано совпадать с провайдером вашей `LLM_MODEL`** — для другой модели поставьте её провайдера или оставьте пустым. |
| **Тёплый retry-seed** | На возврате tester→coder кодер получает план + манифест файлов вместо одной строки. Помогает только когда тестер заворачивает сборку (в эталонных прогонах не срабатывал — скаффолд убирал причину петли). | `V7_WARM_SEED=1` в `.env` |

## Рекомендуемый `.env` для прода

```
OPENROUTER_PROVIDER_PIN=z-ai   # под вашу LLM_MODEL
V7_WARM_SEED=1                  # опционально, для устойчивости на сложных задачах
# scaffold / prepull / dedup / retry — уже включены в коде
```

## Что НЕ сработало (честно)

- **Таксономия архитектору** (добавлена в промпт) — фазу архитектора НЕ ускорила
  (29–45 вызовов, 314–452 с во всех прогонах). Время архитектора уходит на чтение
  контрактов интерфейсов, не на угадывание идентификаторов. Оставлена как
  страховка от ID-ошибок. Ускорение фазы плана — отдельная нерешённая задача.
- **Искусственные лимиты** (max_iters / токен-бюджеты) — сознательно НЕ вводились:
  сходимость достигается устранением причин петель (скаффолд, prepull), а не
  обрезанием.
